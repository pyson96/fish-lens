# DINOv2 ViT-S/14 Linear Probe — 아쿠아리움 보유 어종 100종

## 실험 조건
- **모델:** DINOv2 ViT-S/14를 freeze → CLS 384차원(L2 정규화) → 로지스틱 회귀(multinomial, `class_weight=balanced`)
  - DINOv2는 학습하지 않았고, 선형 분류기만 학습했다.
- **데이터:** iNaturalist captive 사진 중 장면 필터(시장·요리·안내판 제외)를 통과한 **10,956장**
  - 100종, 53과, 종당 66~120장(중앙값 116)
- **분할:** 수족관/장소 그룹(2,503개) 단위 **5-fold StratifiedGroupKFold**
  - 같은 수족관(같은 관찰 기록 포함)은 train과 test 중 한쪽에만 들어간다.
  - 코드에서 assert로 확인했다.
  - 모든 fold의 test에 100종이 모두 포함됐다.
- **하이퍼파라미터:** C는 각 fold의 **train 안에서만** 다시 그룹 3-fold로 나눠 골랐다(후보 0.3~30). 5개 fold 모두 C=10이 선택됐다.

## 결과 (5개 fold 평균 ± 표준편차)

| 지표 | **수족관 단위 분할** | 비교: 관찰 기록 단위 분할 |
|---|---|---|
| **Top-1 정확도** | **0.844 ± 0.016** | 0.851 ± 0.005 |
| **Top-5 정확도** | **0.949 ± 0.008** | 0.952 ± 0.002 |
| **Macro-F1** | **0.839 ± 0.017** | 0.847 ± 0.006 |
| Balanced accuracy | 0.846 ± 0.017 | 0.851 ± 0.006 |
| 과(family) 단위 Top-1 | 0.893 ± 0.013 | 0.897 ± 0.005 |

- 무작위 기준은 Top-1 0.01, Top-5 0.05다.
- **학습 없는 10-NN(0.743)에서 선형 분류기 하나로 Top-1이 0.844로 10%p 올랐다.**
- **수족관 단위 분할과 비교 분할의 차이는 0.7%p뿐이다.**
  - 같은 수족관·같은 개체를 학습에서 봤는지가 성능을 거의 좌우하지 않는다는 뜻이다.
  - 즉 모델이 "그 수조"가 아니라 "그 종"을 학습했다.
  - 대신 수족관 단위 분할은 fold 간 편차가 더 크다(±1.6%p). 어떤 수족관이 test에 들어가는지에 따라 난이도가 달라지기 때문이다.

## 결론
- **DINOv2 ViT-S/14는 아쿠아리움 어종 분류 백본으로 유효하다.**
  - 백본을 학습하지 않고도, 처음 보는 수족관 사진에서 100종 Top-1 84%, Top-5 95%다.
- **남은 과제는 같은 속 안의 세밀한 구분이다.** 해마, 흰동가리, 말라위 시클리드, *Acanthurus* 탱이 해당한다.
  - 이 그룹은 체형이 거의 같고, 무늬·색의 작은 차이나 지느러미 형태로 구분된다.
  - 224px 전체 이미지의 CLS 벡터 하나로는 그 정보가 부족한 것으로 보인다.

## 한계
- **라벨 노이즈:** captive 기록은 연구 등급 검증을 거치지 않는다. 특히 해마처럼 전문가도 구분이 어려운 종은 라벨이 틀렸을 가능성이 있고, 이 경우 정확도가 실제보다 낮게 측정된다.
- **실사용 사진과의 차이:** iNaturalist 업로드 사진은 사용자가 이미 잘 찍은 사진을 고른 것이다. 실제 앱 촬영(흔들림, 반사, 일부만 보임)은 더 어려울 수 있다.
- **장소 그룹의 한계:** 좌표가 없는 기록은 촬영자 단위로 묶어서, 같은 수족관이 서로 다른 그룹으로 나뉜 경우가 있을 수 있다.
- **목록 일부 미포함:** 수조 사진이 부족한 목록 어종 110종은 이번 평가에 없다.

## 다음 단계 제안
1. **물고기 영역만 잘라 넣기:** 탐지 모델로 물고기 영역만 잘라 넣는다. 작게 찍힌 물고기의 세부 무늬를 살리는 것이 목적이다.
2. **백본 크기 비교:** 같은 프로토콜(수족관 분할)로 ViT-B/14와 ViT-L/14를 비교한다.
3. **어려운 그룹 집중 개선:** 해마·흰동가리·탱 그룹에 patch token 평균을 CLS에 붙여 보거나, 백본 마지막 몇 블록만 fine-tuning해 본다.
4. **최종 검증:** 대상 아쿠아리움에서 직접 찍은 사진으로 검증하고, 부족한 110종의 사진을 수집한다.
